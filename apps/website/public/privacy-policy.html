1. Information We Collect

We process necessary information to deliver media streaming, user profiles, and application stability:

  • Authentication Data: User identity via Google Sign-In and Firebase Authentication (UID, verified email address, full name, profile picture).
  • User Profile & Preferences: Usernames, custom profile avatars, marked favorite tracks, custom playlists, and language/font preferences.
  • Playback Analytics & Heartbeat: Listening logs, played tracks, playback resume positions, and periodic AnalyticsHeartbeat signals to track active application sessions.
  • Push Notifications: Firebase Cloud Messaging (FCM) device tokens for track updates and announcements.
  • Telemetry & Diagnostics: Automated crash logs via Firebase Crashlytics and non-identifying telemetry via Firebase Analytics.

2. Device Permissions Used by Mobile Application

The Android app uses only strictly necessary permissions:

  • FOREGROUND_SERVICE and FOREGROUND_SERVICE_MEDIA_PLAYBACK: Required for continuous background audio playback while the screen is locked.
  • INTERNET: Required for streaming audio tracks from Google Cloud Storage and synchronizing with Cloud Firestore.
  • CAMERA & Storage (Optional): Utilized only when users choose to upload a custom profile avatar.

3. Third-Party Service Providers

Backend services are hosted securely on Google Cloud & Firebase:

  • Google Sign-In & Firebase Authentication
  • Cloud Firestore Database
  • Firebase Storage for Media & Images
  • Firebase Cloud Messaging (FCM)
  • Firebase Crashlytics & Analytics

4. Advertising & Data Brokerage Policy

We do not sell, rent, monetize, or disclose user data to commercial advertising networks or data brokers. All data is retained exclusively for app functionality and media delivery.
